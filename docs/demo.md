# Roteiro da demonstração

1. Apresentar as duas organizações e seus DIDs.
2. Entrar como a primeira organização e mostrar que ela também é fornecedora e consumidora.
3. Contratar o plano simples da API de veículos.
4. Consultar dados básicos e mostrar o custo de US$ 0,50.
5. Tentar consultar dados premium e mostrar o bloqueio.
6. Trocar para o plano premium da API da outra organização.
7. Consultar dados básicos e premium, mostrando o custo de US$ 0,20 por requisição.
8. Abrir o resumo financeiro e explicar assinatura, consumo e total.
9. Repetir o fluxo no sentido inverso para demonstrar as duas organizações.
